# E1–E4 实验协议（盲测 · 可证伪 · 席位隔离）

> 状态：PROPOSED（E1 待真实资产清单到位后开跑）。本文件是**协议**，不是结果。
> 每条实验都必须写出「什么结果会推翻 V3 的哪条主张」，否则不予开跑。

## 通用纪律（所有席位强制）

1. **净室**：席位工作目录由 `git archive` 导出（无 `.git`），物理删除答案面并校验残留为 0。
   实测依据：worktree 共享 object DB，`git log --all` / `git show <branch>:<file>` 可直取答案，
   且 `workspace-write` 不限读——**任何"约定不看"都不构成控制**。
2. **脱敏**：刺激材料内的结论性标注（缺口编号、判语、既有报告的结论段）一律剥离并计数入账
   （见 `e0/scrub-corpus.py`；E0 实测：4 处标签写在刺激正文内）。
3. **canary**：投放只含诱饵的伪答案文件；席位输出若引用 `GAP-99` / `AUDIT KEY` → **整次作废**。
4. **模型路由（2026-11-01 用户指令，见 `SUBAGENT_ROUTING.md`）**：只用 `qiyuan-self/qwen3.8-flash-next`
   与 `qwen3.8-27b`；判定与物理席位走 flash-next，机械与格式化席位走 27b。
   **由此产生的混淆必须显式处理**：案例构造方与被测席位可能同为 flash-next → 存在相关性盲区
   （出题者格外容易、或格外察觉不到自己造的错）。控制两条：
   ① **作者 ≠ 复核者**：案例库物理复核由另一席独立做，且复核席不得看 keys；
   ② **模型敏感性对照**：关键档位（T4/T5）各加一席 `27b`，与主臂 `flash-next` 同题对照；
      两模型答对率之差单独报告，**不得**把单模型结果当作难度常数。
5. **互不可见**：席位之间不共享目录、不读彼此输出；每席只看自己的记录面规格 + 素材。
6. **不声称硬隔离**：docker 只读容器当前不可用；控制强度只声称到「无意泄漏已切断 + 有意泄漏可检测」。
7. **停止条件**：任一席 canary 触发，或脱敏校验非 0，本轮全部结果作废并记 N/A（**N/A 不得记为 PASS**）。

## E1 · 真实资产重建对照（必要性主实验）

| 项 | 内容 |
|---|---|
| 问题 | 记录一次真实科研，究竟需要多少本体？ |
| 素材 | 3 个真实案例（由资产普查选定；**排除条纹相机/合作方范围**；素材内不得含既有结论文档） |
| 三臂 | **A** 扁平信封（PoC 信封：三通道 + 锚 + unknowns，**无图无类型对象**）／**B** V3 五类对象 + H/S/R 最小可用面（含五态字段、四时间、Revision 引用）／**C** 现状 V1（Claim/Fact/Relation + `RELY_ON`） |
| 设计 | 拉丁方：3 案例 × 3 记录面 = 9 席（先跑 1 案例 × 3 臂的 pilot） |
| 度量 | ① 记录条数 ② 记录成本（步数/token，作成本代理）③ **表达不能事件数**（席位显式声明"无处安放"而降级的次数）④ 关键认识转折覆盖率（评分侧独立核对表）⑤ **B 独占表达条目集**（A/C 写不出、B 写得出） |
| 推翻什么 | 若 ⑤ = ∅ → 五类对象在该案例**不必要**；若 ⑤ 集中在 ≤2 类概念（预判：可撤回状态、证据条件）→ 那 2 类就是**最小必需概念集**，其余应移出内核 |
| 已知弱点 | 席位是 LLM 而非人类研究者；记录成本是代理指标；真实资产轨迹本身不可完全复现（用户自陈），故"关键转折核对表"由评分侧独立构建并与席位输出解耦 |

## E2 · 可达性 ≠ 被注意到（攻击现有指标的解释）

| 项 | 内容 |
|---|---|
| 问题 | P4 的"检出率"能否解释为"评审会注意到"？ |
| 做法 | 同一（脱敏）语料渲染成两种评审视图（扁平清单 vs 双视图导航），席位在**注意力预算受限**（限定步数、禁止全量 dump）下产出"我要质疑哪些点"，与 `planted.json` 对齐 |
| 推翻什么 | 若 noticeability ≪ reachability（尤其双视图相对扁平视图无优势）→ 契约里以"检出率"支撑的能力叙述**失去解释力**，须改指标 |
| 备注 | E0 已证明 7 个缺口全是完整性缺口、且扁平 linter 7/7；E2 补的是"人/LLM 侧"那一半 |

## E3 · 盲设本体（设计空间是否被闭集排除）

| 项 | 内容 |
|---|---|
| 问题 | 五类对象是**发现**还是**约定**？ |
| 做法 | 3 席不知道 V3 分类法，仅给同一批真实记录需求（取自 E1-A 输出 + 对抗案例），要求"用尽可能少的类别与状态轴表达完整" |
| 度量 | 类别数分布；是否出现 ≤3 类方案；V3 独有区分（Assertion 与 Proposition 分离，RD-06）被独立复现的比例；对抗案例下的**席位间分歧率** |
| 推翻什么 | 若 3/3 收敛到 ≤3 类 → "5 类"是约定；若 Proposition 身份判定分歧率高 → "真值条件稳定的 PropositionID"这一前提在**操作上**不成立（不是哲学争论，是可判定性失败） |

## E4 · 隐蔽错误的难度谱系与价值归因（拆成 E4a / E4b）

> **设计前提（用户 2026-11 反馈记入）**：gpt-streak 的 screen/rms 行语义错误属于最易档——
> 判别线索在**同一时刻手上的两条记录里自相矛盾**，不需要跨会话召回。用它做对照，
> 三臂都会抓到，实验**无分辨力**。真实需要的难度是：**每条记录各自都正确、单位都合法、
> 数字都可复现，错在记录之间的语义前提悄悄变了**——线索在库里可回溯，但没人会主动想到去看。

### 难度谱系 T0–T5（按"可检性来源"分级，不按物理深度）

| 档 | 错误形态 | 物理实例（非条纹相机范围） | 可检性来源 | 谁够用 |
|---|---|---|---|---|
| **T0** | 单条不自洽 | `based_on` 指向不存在的 seq；工件无 sha；依据落在 `run.failed` | 完整性谓词 | **扁平 linter**（E0 实测 7/7） |
| **T1** | 同条件双记录矛盾 | 同一 deck 两次分析给出互斥读数；两文档引用同一 run 却报不同出口能量 | 等值/区间比对 | 扁平 linter + 一次 join |
| **T2** | **标签不变、口径变了** | 归一化 vs 几何发射度（差 βγ）；RMS vs 95% 包含 vs 峰值；能散 RMS vs FWHM/2.355；相位约定 0°=波峰 vs 过零（同一符号的 ΔE 含义翻转）；峰值电流 vs 平均电流（占空比变了）；束斑 σx（单发）vs 时间积分像；铜支架温升 vs 真空室外壁温 | 需要"这个量**怎么算出来的**"被登记 | 一张**量口径登记表**即可；不需要图 |
| **T3** | **共变混淆**（每个数都对，结论错） | 扫描顺序与日间温漂同向；调磁体电流→铁芯温升→场滞后与热漂移同时进结论；改腔压时同时动了调谐→场分布与幅值一起变；降流强研究 emittance growth，实际改变的是表观 vs 固有发射度的适用域；网格与时间步被同一动作同时改（CFL 耦合）；sim 取 z₁、exp 测 z₂，中间漂移段未计 | 需要"什么被**固定**、什么**共同变化**"的实验设计记录（配伍/随机化/对照） | 需要**设计层记录**，纯记录与图都不够 |
| **T4** | **模型适用域越界 / 工具静默改参** | 求解器自适应把 `dE/E` 改了却沿用旧 run 名 → **run 身份混淆**（`docs/poc/V3_POC_EXECUTION_PLAN.md` §4-P2 自点过此风险）；场图插值在边界外被静默裁剪；2D3V 结果用于纵向相空间结论；高电荷场景缺 SC/CSR 仍谈 emittance 增长；宏粒子数未收敛把噪声读成系统效应；粒子打到边界丢失被当作物理衰减；网格加热被读成 tune shift | 需要"这条结论**依赖哪些前提**"+ 软件版本 + 输入指纹 + 参数变更史 | **这一档才真正需要跨会话把旧前提拉回当前视野**——即 V3 关联召回的靶心 |
| **T5** | **欠定被当成已定** | 腔压与相位可同调得到相同出口能量与相空间分布的简并，却宣称参数已定；单工况数据支持双指数模型 | 需要**否定性状态**（"证据不足以区分"）可被登记并可被取回 | V3 的 UNKNOWN/欠定表达正对上，但当前重心未测它 |

**核心可证伪命题（比原 E4 锋利得多）**：V3 的 PoC 语料**全部落在 T0/T1**（E0 已证 7 个缺口均为完整性缺口，
扁平 linter 7/7），而其能力叙述（"帮评审发现可能遗漏的因素"）指向 **T3–T5**。
若真实研究中的修正事件也集中在 T0–T2，则 V3 的核心能力**打偏**；若集中在 T3–T5，则方向对但
**从未被测过**，且需求会指向 T2 的口径登记、T3 的设计记录、T5 的否定性状态——**而不是当前的双图谱与五类对象重心**。

### E4a · 难度谱系标定（真实资产挖掘，先于盲测）

| 项 | 内容 |
|---|---|
| 输入 | 真实资产中**已被修正/推翻过的结论**（排除条纹相机与合作方范围） |
| 做法 | 席位只读工件与修订痕迹，产出「修正事件」清单：原信念 → 修正后信念 → 线索当时是否已在记录中 → **所在档 T?** → 若当时库里有全部记录，是否只需"被想到去看" |
| 度量 | **T0–T5 分布**（这是主结果）；"线索当时已在库中"的比例；"线索当时根本未登记"的比例 |
| 推翻什么 | T0–T2 占多数 → 双图谱与对象化对本案例族**不必要**（linter + 口径表 + 设计记录即可覆盖）；T3–T5 占多数 → 现有 PoC **测错了对象**，须按本谱系重做植入语料 |
| 注意 | 事件必须由工件独立支撑（文件、版本、修订痕迹），**不得**采信资产作者的记忆或结论文档 |

### E4b · 分布式线索盲测（难度驱动的三臂对照）

| 项 | 内容 |
|---|---|
| 案例构造配方 | **稳定标签**：错误始终藏在一个从未改名的量/ run 之下；**线索前置**：口径变更/共同变化/参数被改写成一条**早期**记录，后续结论只用标签引用，正文绝不提及；**干扰项**：4–8 条同类但无关的记录；**每档至少 2 例**，T2–T5 各一组 |
| 可检性自检（构造后必做） | ① 全知席位（给全部记录、无任务提示、无限预算）答对率 → 证明"线索确实在库中可见"；② 限注意力席位（步数上限）答对率 → 这才是被测能力。①低则案例**不合格**（属于"没记下来"，不是"没召回"，不得混入） |
| 四臂 | (a) 扁平信封 + 三通道纪律（无类型对象，可 grep） (b) V3 类型对象 + 双视图 (c) 自由笔记 (d) **E0 的扁平确定性 linter**（作为 T0/T1 的诚实上限） |
| 度量 | 抓到率（分档报告）、抓到所需步数/记录条数、误报数、**"线索被取回"率**（区分"没记下来" vs "记了但没找到"——这是唯一能验证 V3 核心机制的指标） |
| 推翻什么 | 若差异只在 T0–T1 出现且 (d) 已覆盖 → 类型化本体与双视图**无可测贡献**；若 T3–T5 上 (b)>(a)>(d) → V3 方向成立，**但必须把 T3 的设计记录与 T5 的否定性状态提到内核首屏**（当前 G1 契约两者都不是重心） |
| 已知风险 | LLM 席位具备物理先验，可能"靠外部知识"答对而非靠召回 → 记分规则要求席位**必须引用记录 id** 才算抓到，未引用的正确猜测单列，不计入召回能力 |

## E4b′ · 写时拦截对照（**与前瞻性主张同形状的检验**，2026-11-01 用户裁定后新增）

> **为什么加这一节**：用户裁定「双图谱、五类对象、内核与插件框架」解决的是
> **「今后如何逐步建立干净的科研工作区，并保证结果可信、可审计」**，
> **不是**「如何清理并重建一个此前混乱的工作区」。因此：
> - **遗留资产（E4a）不能否定这套设计**——它只回答"哪一类写时义务是承重的"（需求排序器）；
>   用"事后能否检出"给前瞻性系统打分，测的是**下界**。
> - **E5 的一切命中率一律标注为「读时检出下界」**，不得写成"某机制已足够"。
> - 前瞻性主张必须由**前向**检验：让席位在承担/不承担写时义务的两种条件下**继续做研究**，
>   看错误是否**根本没有被写进去**。这才是与主张同形状的对照，取代"给一堆旧记录找错"。

| 项 | 规定 |
|---|---|
| 刺激材料 | E4b 案例的**前缀**：线索记录 + 干扰项 + 已登记口径/前提（**删去结论记录**）。席位不知道案例的答案 |
| 席位任务 | **继续这项研究**：基于前缀写出下一步该做的分析与结论（产出若干**新记录**），不给"找错"提示 |
| A 臂（自由） | 只要求扁平信封 + 三通道分离（source/inference/suggestion），无强制字段 |
| B 臂（承担写时义务） | 写入前必须声明：①每个被比较量的**定义/表示登记**；②每条结论的**前提清单 + 所依赖工件的版本指纹**；③跨记录比较时的**同口径一致性声明**；④run 的**终态声明**。缺任一项 → 该记录**拒绝写入**并要求列明缺什么 |
| 主指标 | **错误引入率**：席位新写的结论是否复现该案例隐藏的错误（按档位分别报告）；**自检拦截率**：B 臂在写入前自己发现并列出口径/前提不一致的比例；**记录成本**：新增字数、字段数、耗时 |
| 次指标 | 席位是否主动取回前置线索记录（引用其 id）——与 E4b 的"线索被取回率"同口径，可跨实验比较 |
| 推翻什么 | **A 臂错误引入率 ≈ B 臂** → 写时义务对可信度**无可测贡献**，这是对设计目标的直接否证；<br>**B 臂显著低** → 义务有效，并可定位**哪条义务拦哪一档**（预期：T2←口径登记，T4←前提+版本指纹，T3←设计登记，T1←run 终态登记） |
| 已知局限 | 席位是 LLM 而非人，先验可能直接避开错误（两臂同受影响，差值仍可用）；案例是构造的；样本小；**结论不得外推到人类研究者的习惯** |
| 与 E4b 的分工 | E4b 测**读时召回**（V3 关联机制的既有主张）；E4b′ 测**写时预防**（用户裁定的真实目标）。两者分开报告，**不得互相顶替** |

## 结果登记

每个实验完成后在本区追加 `RESULT-E<n>.md`：语料指纹（sha256）、席位模型与参数、脱敏与 canary 校验行、
逐条读数、**以及"本轮不能声称什么"**。状态词汇上限为 MEASURED，不产出 GO/NO-GO——
GO/NO-GO 属用户产品级裁决。
