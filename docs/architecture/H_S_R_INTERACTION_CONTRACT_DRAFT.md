# H/S/R 领域交互契约：操作语义与状态转换

> **PR #42 · DRAFT-PROPOSAL · 2026-10-28。** 定义五类对象在 H/S/R 三系统上的**领域语义操作**与状态转换。共享约定见[共同底座](H_S_R_DOMAIN_FOUNDATIONS_DRAFT.md)；字段名只在各对象契约中定义（[Entity](H_S_R_ENTITY_CONTRACT_DRAFT.md)、[Concept](H_S_R_CONCEPT_CONTRACT_DRAFT.md)、[Association](H_S_R_ASSOCIATION_CONTRACT_DRAFT.md)、[Argumentation](H_S_R_ARGUMENTATION_CONTRACT_DRAFT.md)、[Proposition](H_S_R_PROPOSITION_CONTRACT_DRAFT.md)）。
>
> **本文件不是服务设计**：不规定 HTTP/MCP 接口、函数签名、进程边界、事务或调用顺序。H/S/R 是**职责正交**，不要求三个服务，也不要求对象按 Entity→Association→Argumentation→Proposition 顺序创建。文中“系统做某事”指领域层必须出现的效果，不指某个进程被调用。**Proposed，不表示已实施。**

## 1. 读法与通用规则

| 编号 | 规则 |
| --- | --- |
| IC-00 | 操作可按研究者实际需要以任意顺序发生。下文的分组只是职责归属：**H 记录、S 定含义、R 查论证与接纳**。 |
| IC-01 | 每个写操作的效果 = **追加**（新对象 / 新修订 / 新记录 / 新报告）。不存在“就地改写已登记内容”的合法操作。 |
| IC-02 | 每个写操作必须留下可归因记录：主体、`recorded_at`、来源材料引用（`source_refs`）。不可归因的写操作只允许落到“不可归因”状态并被查询暴露，不允许伪装成已确认。 |
| IC-03 | 规范化检查、影响分析、状态投影是**读侧派生**：它们产生报告或视图，不直接修改对象字段、评价或接纳。 |
| IC-04 | 任何操作都不得隐式转换状态轴（A1–A8）；跨轴的效果必须由**另一个显式操作**产生。 |

### 1.0 结果的两个视图（所有查询与检查共用）

| 视图 | 谁可见 | 内容 |
| --- | --- | --- |
| **审计视图** | 同时对被检查对象所在空间与被屏蔽范围有可见权的主体 | 完整 `outcome`/`reason_code`/`coverage`，含 `REF_UNRESOLVED` 与 `WITHHELD_REFERENCE` 的区分 |
| **呈现视图** | 其他一切调用者 | `sanitize()` 之后：两者合并为 `UNVERIFIABLE_REFERENCE`、`coverage → NOT_DISCLOSED`、无计数无标识；可说明“依赖未能完整核验” |

两个视图共用同一份不可改记录，脱敏只发生在呈现层（SP-10）。理由：否则一个猜测 ID 就能靠规范化结果的差异反推他空间是否存在该对象（XC-25）。

### 1.1 统一失败语义（各操作只引用代号）

| 代号 | 情形 | 领域后果 |
| --- | --- | --- |
| `F-INCOMPLETE` | 必填角色缺失（`ABSENT`） | **对象仍保存**；规范化 FAIL 项入账；禁止进入被认证组合 |
| `F-UNRESOLVED` | 引用目标在**本空间**不存在/未登记 | 引用原样保留并登记悬挂；不阻断保存；依赖它的派生视图标注不可判定；对外呈现与 `F-WITHHELD` 合并（见下行） |
| `F-WITHHELD` | 目标在其他空间或无权限 | 返回 `WITHHELD`；不泄漏存在性；不报告“不存在”。**对无核验权的调用者，本码与 `F-UNRESOLVED` 的对外呈现必须不可区分**（`UNVERIFIABLE_REFERENCE`），差异只保留在审计视图（SP-07、RPT-09） |
| `F-CONFLICT` | 新登记与已登记记录**可能**针对同一事项给出不相容主张 | 两者并存，系统只产生**可重叠提示**（机器启发，非主张）；冲突是否成立须由主体另行显式登记主张（IC-S9），系统不得自动登记为“冲突已确认”、不自动裁决、不自动选边（RD-10 修订） |
| `F-DENIED-AUTH` | 对目标空间**有写权限**，但缺少作出该**业务动作**的授权（如正式接纳、豁免） | 声明在本空间保存为“未生效声明”（`AUTHORITY_UNVERIFIED`）并标注原因；不改变任何状态投影（SP-09(a)、PR-A1…A4） |
| `F-DENIED-WRITE` | 对目标空间**没有写权限** | **拒绝写入**：目标空间不产生任何记录，也不返回目标内容；不得以“保存未生效声明”为名绕过空间隔离，也不得改投第三方空间代收后冒充原空间（SP-09(b)） |
| `F-SCHEMA-INVALID` | 结构不符合声明类型，无法作为正式对象解析 | 落为 H 原始记录（保留原文与来源），不冒充正式对象，也不冒充通过门禁 |
| `F-CHECK-UNAVAILABLE` | 检查器/资源/时间不可用（超时、缺文件、崩溃） | 相关项 `INDETERMINATE(CHECKER_UNAVAILABLE)`，层级 `INDETERMINATE`；**绝不**转为科学否定或“检查未通过＝结论为假” |
| `F-PARTIAL` | 预算、分页、权限或深度限制导致部分结果 | 返回结果 + 边界标注（限制类型；权限类限制按 SP-03 的**粒度受限**标注：只说“有内容被权限过滤”，不给精确计数或可反推存在性的派生量） |
| `F-RETRYABLE` | 外部检查或导出暂时失败 | 原记录不变；重试产生**新报告**，不改写旧报告 |

## 2. H：历史、来源与回放

| 操作 | IC-H1 登记对象初始记录 | IC-H2 登记对象修订 |
| --- | --- | --- |
| 操作语义 | “本主体此刻登记了一件对象记录” | “本主体此刻补全/更正此前那件对象的记录” |
| 输入 | 对象载荷（含 kind、space、身份构成字段或 `UNKNOWN`）、来源材料、`claimed_time`（可选） | 目标 `object_id` + **基 revision**、变化集、`revision_class`（补全/更正/替代声明）、理由 |
| 前置条件 | 载荷可解析（否则 `F-SCHEMA-INVALID`）；space 归属明确；无同名对象自动合并 | 基 revision 存在且为当前可修订端；变更未触及身份构成字段（否则要求新对象，见 G-REV） |
| 结果 | 新 `object_id` + `r1` + 登记事件 | 新 `revision_id` + 事件；旧 revision 保持可精确引用 |
| 不变量 | 不推断缺失字段（UN-02）；不按相似度合并；不隐式产生评价/接纳 | 不重排历史序；不使锚定旧 revision 的检查/评价/接纳漂移（RV-03） |
| 失败语义 | `F-SCHEMA-INVALID` / `F-WITHHELD` / `F-UNRESOLVED` | `F-INCOMPLETE` / `F-CONFLICT` / `F-WITHHELD` |

| 操作 | IC-H3 登记原始未解析材料 | IC-H4 追加 Assertion 链 |
| --- | --- | --- |
| 操作语义 | “保存一份尚不能作为正式对象解析的原文及其来源” | “声明这两件命题版本属于我维护的同一条陈述历史” |
| 输入 | 原文、来源、声明者、可选候选提示 | 链标识（新或旧）、新成员 `PropositionID@rev`、`relation_claim ∈ {CONTINUES, REVISES, REPLACES, UNKNOWN}`、理由 |
| 前置条件 | 无（最低门槛就是能保存） | 成员命题已登记；声明主体可归因 |
| 结果 | H 原始记录，可被引用与后续抽取；**不**产生正式对象，也**不**产生 S-L0 通过声明 | 链成员追加；链不携带含义与真值（ID-06） |
| 不变量 | 原文不被“规范化”静默改写；抽取产生的候选另成新对象 | 链可先后指向不同 PropositionID；链不构成等价声明；不产生第二套陈述真源 |
| 失败语义 | `F-RETRYABLE`（导入工具失败） | `F-UNRESOLVED` / `F-DENIED-AUTH`（非链主声明另记） |

| 操作 | IC-H5 登记资源可用性检查 | IC-H6 历史回放查询 |
| --- | --- | --- |
| 操作语义 | “此刻对某载体做了一次可用性检查，结果是 X” | “按某个知识截点，能重建出某个对象时刻的什么状态” |
| 输入 | Entity 引用、检查方式、结果 ∈ `A8` 取值、时间、检查者 | **两个独立时间条件**（T-05）：`recorded_as_of`（知识截点：截至何时已登记的信息可见）与 `described_at` / `described_during`（对象时间：想了解哪个时刻的装置/模型/实验状态），二者各自可选但缺省值必须在结果中回显；视角 ∈ {`as-recorded`（当时已知）, `as-claimed`（当时声称发生）, `both`}；**版本选择** ∈ {`at-revision`（精确 revision）, `chain-at`（某 Assertion 链在该截点的成员）, `as-declared-by`（某主体当时采用的版本）}；`space` 与授权上下文、可选主体与 Scope 过滤 |
| 前置条件 | 被检 Entity 已登记（可 `UNRESOLVED` 引用外部目标） | 视角与版本选择必须显式；两个时间条件允许缺省但必须回显实际取值（缺 `described_*` 即只回答“当时的登记面貌”，不得被读成对象时间也等于该截点）；不同主体的采用不得合并为单一“当前版本”（T-01、T-05） |
| 结果 | 新检查记录；A8 轴的最新投影随之变化 | 可复现投影 + 缺失/未映射/未知清单 + 截点声明 + 每条结果的来源与采用主体 |
| 不变量 | 检查失败**不删除** Entity 与过去登记；不伪造替代数据；不改动旧检查记录 | 晚到登记不得出现在其 `recorded_at` 之前的 `as-recorded` 视图（T-02）：**先**按 `recorded_as_of` 过滤可见记录，**再**按 `described_*` 过滤对象时间，两步顺序不得交换或合并；按 `at-revision` 查询永不因新修订漂移（ID-04）；结果必须标注实际使用的两个时间、视角与版本选择 |
| 失败语义 | `F-RETRYABLE` / `F-WITHHELD` | `F-PARTIAL` / `F-WITHHELD` |

| 操作 | IC-H7 缺失与断链查询 |
| --- | --- |
| 操作语义 | “列出我关心的范围内哪些引用未解析、资源不可取回、字段未声明未知、结果被截断” |
| 输入 | 范围（空间/项目/对象集合）、类别过滤、截点 |
| 前置条件 | 授权上下文明确；过滤条件不得被误当作“范围已穷尽” |
| 结果 | 分类清单：`UNRESOLVED`（同空间缺失）/ `UNRETRIEVABLE` / `ABSENT` 必填项 / `INDETERMINATE`（因权限未能判定，仅标注“存在未能判定的引用”，不给计数）/ 截断点 |
| 不变量 | 每类必须区分呈现；空结果只说明“本查询范围内无此类记录”；`UNRESOLVED` 与权限不可见**不得合并统计**，也不得经合并总数反推后者（SP-07） |
| 失败语义 | `F-PARTIAL`（必须报告，不得静默） |

## 3. S：语义、规范化与概念

| 操作 | IC-S1 创建正式对象 | IC-S2 请求规范化检查 |
| --- | --- | --- |
| 操作语义 | “把一件对象作为某 kind 纳入正式语义层”（内部可紧接 IC-H1） | “在指定契约版本下检查这件对象达到哪个规范层级” |
| 输入 | kind、space、身份构成字段（允许 `UNKNOWN`）、来源 | 目标精确引用 + 契约/检查器版本 + 检查范围 |
| 前置条件 | kind 合法且不可变；空间明确；可解析 | 对象已登记；检查器可用（否则 `F-CHECK-UNAVAILABLE`） |
| 结果 | 对象 + 事件 + 首轮报告（verdict + FAIL 项 + `declared_gaps`） | **新检查报告**：每项 `PASS` / `FAIL`(+`DEFICIENCY`\|`VIOLATION`, 含原因码) / `NOT_APPLICABLE` / `INDETERMINATE`，加 `declared_gaps[]` 与 `coverage`；如实声明的未知不阻止达成（RPT-05）；不写对象真值 |
| 不变量 | 不因缺字段而拒绝保存；不猜值；不因“看起来像已有对象”而合并 | 报告不可被后续重检改写（C11）；`S-L1 PASS ≠ 原意被确认 ≠ 正确` |
| 失败语义 | `F-SCHEMA-INVALID` → 转 IC-H3 | `F-CHECK-UNAVAILABLE` → 报告 `INDETERMINATE`，保留旧报告 |

| 操作 | IC-S3 补全语义 | IC-S4 建立新命题 |
| --- | --- | --- |
| 操作语义 | “在不改变对象身份的前提下补角色、区间、World/Scope、概念引用” | “登记一件真值条件不同的新命题内容” |
| 输入 | 基 revision + 变化集 + `truth_condition_claim`（Proposition 时必填） | 新命题内容、`truth_condition_claim = CHANGED`、来源、可选链引用 |
| 前置条件 | 变化不触及身份构成字段已声明值（G-REV、各 `*-ID-*` 判据） | 目标差异可说明；不要求先有论证或评价 |
| 结果 | 新 revision + 新报告；历史锚定不变 | 新 `PropositionID`；可另建链、等价候选、差异元命题 |
| 不变量 | 概念/World 新版本不倒灌旧含义（C11） | 不得由“修订更省事”而把真值条件变化写成同 ID（PR-ID-4） |
| 失败语义 | `F-INCOMPLETE`（仍保存）/ `F-CONFLICT` | `F-CONFLICT`（与既有命题疑似同义时提示，不合并） |

| 操作 | IC-S5 概念修订 | IC-S6 登记原意确认 |
| --- | --- | --- |
| 操作语义 | “对该概念版本作词法或含义修订” | “某主体确认某**精确 revision** 表达了其原意” |
| 输入 | `revision_class ∈ {LEXICAL, SUBSTANTIVE}`、新内容、理由；`SUBSTANTIVE` 需给出影响面自述 | 目标精确 revision、主体、结论 ∈ {CONFIRMED, DISPUTED}、依据 |
| 前置条件 | 概念已登记 | 目标 revision 精确；主体可归因 |
| 结果 | 新 revision；`SUBSTANTIVE` 触发**定向重检提示**（受影响引用清单，供人工决定复审） | 状态轴 A3 更新；不改变 S-L1 结果 |
| 不变量 | 新别名不使历史检查失效；重检提示**不**自动改写旧 PASS，也不自动宣布旧命题为假 | 确认是主观登记，机器 S-L1 与之独立；他人无法代替主体确认 |
| 失败语义 | `F-CONFLICT`（含义分歧并存） | `F-DENIED-AUTH`（无资格者只能登记为普通评价） |

| 操作 | IC-S7 登记语义对齐声明 | IC-S8 高阶命题定位 | IC-S9 登记等价候选 / 冲突与替代主张 |
| --- | --- | --- | --- |
| 操作语义 | “某主体声明两个精确语义版本之间存在某种对应” | “登记一个关于其他对象/命题的命题” | “某主体主张：这两个对象可能同一（或同名却为两个）；或：这两条已登记记录互不相容／后者在前者所述范围内取代前者” |
| 输入 | `from@rev`、`to@rev`、关系 ∈ {EXACT_MAP, DECLARED_MAP, ASSUMED, UNKNOWN}、依据、声明者 | 提及集合（精确引用 + 角色，允许 SELF） | 两个（或多个）精确引用、主张 ∈ {POSSIBLY_SAME, DEFINITELY_DISTINCT, NAME_COLLISION, INCOMPATIBLE_AS_STATED, SUPERSEDES_AS_STATED}、依据（来源 + 说明文本）、声明者 |
| 前置条件 | 两端可解析或 `UNRESOLVED` | 提及端点可解析；自指合法 | 各对象已登记；声明主体可归因 |
| 结果 | 对应声明（Association）或元命题 | 新命题；不改变被讨论对象状态 | **独立的主张记录**（高阶 Proposition 承载主张内容 + 精确提及各被主张对象@rev）；被提及对象与其字段一律不被改写，“双方可见”由可重建视图提供 |
| 不变量 | 未通过检查时**允许**保留候选或条件性连接，但不得标为“已对齐”（C05）；不得用名称/数值/相似度自动继承证书 | 自指不引入 `True(P)` 消解；讨论 ≠ 修改 | **任何情况下都不自动合并、不自动重定向引用、不自动把两条记录标记为冲突**（ID-07）；合并只能由有权主体显式登记新记录完成，且旧对象的既有精确引用仍解析到旧对象。机器的“可能重叠/可能冲突”提示与主体的冲突主张是两种不同记录，前者不产生后者的效果（F-CONFLICT） |
| 失败语义 | `F-UNRESOLVED` / `F-WITHHELD` | `F-UNRESOLVED` | `F-WITHHELD`；裁决所需授权不可确认时记 `F-DENIED-AUTH`（有写权限）或 `F-DENIED-WRITE`（无写权限），候选保持未决 |

## 4. Association：建立、修订与采用

| 操作 | IC-A1 建立关联 | IC-A2 修订关联 | IC-A3 在研究范围中采用关联 |
| --- | --- | --- | --- |
| 操作语义 | “某来源声称一项关系记录” | “补全该记录的区间/来源/注记” | “本研究本次按某政策使用这条记录” |
| 输入 | 关系类型@rev、参与端点+角色、方向、`described_interval`、来源主张、语境 | 基 revision + 补全内容 + 类别 | 采用者、`adopted_ref@rev`、`adoption_scope`、`adoption_at`、`basis_ref` |
| 前置条件 | 类型定义可解析或候选类型已登记；端点可解析或 `UNRESOLVED` | 变更不触及身份构成字段（AS-ID-*） | 被采用记录已登记且精确；采用者明确 |
| 结果 | 新关联 + 事件；进入可检索集合 | 新 revision；旧描述仍并存 | 采用记录（独立记录，A5 载体） |
| 不变量 | 无全局真值；不推断真实切换时刻；质疑不删除（C01） | 不得实现为“更新为现状”（AS-ID-6） | 采用 ≠ 验证 ≠ 接纳（AD-03）；不要求每次重复人工认证现实（AD-01）；外推到新场景须新采用记录与明示假设（AD-02） |
| 失败语义 | `F-UNRESOLVED` / `F-CONFLICT`（并存）/ `F-WITHHELD` | `F-CONFLICT`（应改新关联时提示） | `F-UNRESOLVED` / `F-DENIED-AUTH`（记为未生效采用） |

## 5. R：论证、条件、验证与接纳

| 操作 | IC-R1 创建/补全/关闭论证 | IC-R2 提交并检查论证 |
| --- | --- | --- |

## 7. 明确不存在的行为

不存在（每条都对应一处可测试的拒绝）：自动把关联升为论证；自动把检查 PASS 升为接纳；自动合并相似对象/命题/概念；自动撤销受质疑前提的所有结论；自动删除被攻击记录；自动补全缺失字段；自动把权限过滤或检索失败当作科学否定；自动跨 ResearchSpace 读取；自动重算并覆盖历史 PASS；自动分派或唤醒科研 Agent（运行编排在系统之外）；**自动因为研究者如实声明 `UNKNOWN` 而降低其规范化层级**（RPT-05、UN-06）；**自动把机器的“可能冲突”提示升格为主体的冲突主张**（AS-CF-3、F-CONFLICT）；**自动因为 `UNDERCUT`/`REBUT` 标记而使目标论证失效或显示为已反驳**（CN-04）；**自动把被权限屏蔽的检查项判为通过或不通过**（RPT-03、SP-08）；**自动替研究者判定某次改动是原意补全还是新判断**（RV-06）；**自动向无写权限的空间写入“未生效声明”**（SP-09、`F-DENIED-WRITE`）。

## 8. 与非对象记录的对应

H 事件、来源引用、采用记录、检查报告、可用性检查记录、投影快照都不是五类对象（ID-08）。它们可被精确引用，但不得被当作论证结论端、评价目标之外的语义端点，也不得各自另存一份“当前有效状态”。
