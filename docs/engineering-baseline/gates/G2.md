## 已知限制 / 遗留（诚实登记）

- YAML 子集解析器刻意最小（仅覆盖自家两文件形态）；词汇或结构越界会 fail-loud
  （unparsable = 检查红），不做通用 YAML。
- probe 映射规则内嵌内核（PROBE_RULES）；归属在 YAML——规则演进集中在一个文件
  是有意取舍（G2 判据 6），YAML 化留给 EB3+ 真实需求出现时。
- `docs:check` 的链接检查豁免冻结面与 `docs/BASELINE_*`（历史原文含仓外路径引用，
  豁免≠放行：它们本就声明 UNKNOWN 缺口）。
- EB2 实际用量 ≈ 2h ≪ 12h；实验计数 ≈ 7 ≤ 12。
