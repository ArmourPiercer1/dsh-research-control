# OWNERSHIP · 主执行体到底要推进多少（按 §3.6 L0–L5 的归属拆）

依据 `docs/design/V3_TYPED_RESEARCH_EPISTEMICS_ARCHITECTURE_DRAFT.md` §3.6 原文：
**L0 Normalized Submission** = 主科研 Agent 用结构化自然语言定位**对象/引用来源/关系角色/结果**，
提出推理时**声明方法**，**记录不确定信息**；服务只执行**低成本**身份/格式/引用/声明检查；
「L0 通过后提交者可用该结果继续探索，**不要求此刻有完整 TypedFormula/Lean 代码**」。
**L1** 的术语/对象身份/World/Scope 规范化由**外部形式化 Agent** 完成（"应优先快速回访原作者，不得擅自将新假设写入原意"）。
**L2–L5** 明确标注"待讨论/候选能力"。原始 ResearchFinding 先存不可变版本，**未完成确认应能查询**。

## 2. 真正**不可委派**给旁路的只有三类（旁路推不出来，因为不在工件里）

| 不可委派项 | 为什么旁路补不了 | L0 里的位置 |
|---|---|---|
| **外推意图**：这话是只说本工作点，还是说整个构型族 | 措辞之外的作者意图；文档禁止旁路"擅自写入原意" | `角色` + `结果` 的措辞 |
| **未测清单种子**：刚才自己没做什么 | 负知识不在任何工件里 | `不确定` |
| **参照有无**：要不要引基线、有没有引 | 作者的选择；旁路只能查"引了没有" | `参照` |

其余（World/Scope/概念/AST/**互斥测量检测**/**退化最优检测**/**跨 run 反例检索**）旁路都能自己从工件算出来，
**主执行体一行都不用写**。

## 3. 更要紧的后果：成本可以后置，**但出口门不能**

按"提交那一刻可判吗"重排 ARM1 的 13 条：

| 判定时机 | 条目 | 数 |
|---|---|--:|
| **出口时刻直接可判**（只需 L0 字段：角色/结果措辞/方法/未测/参照）→ P4、P6 | I2 I7 I8 I9 I10 I11 I12 | **7** |
| 准实时（旁路读工件即可，秒级）→ P3、P5 | I1 I4 | 2 |
| 需预计算冲突/设置索引才可出口判，否则**事后追认** → P1、P2 | I3 I5 I6 | 3 |
| 只能事后（跨 run 检索，且 HSR SD-20 下只能标记）→ P7 | I13 | 1 |

**你最在意的那一类（不可达/极限/跳过复核）5/5 全落在"出口时刻直接可判"**，
且所需入参正好就是 §2 那三类不可委派字段 ⇒ **把它们放进 L0、而不是留给旁路，是设计上的必选项**。
反过来，**口径冲突类（P1）在真实时序里多半是事后追认**——除非旁路预先维护库级口径/设置冲突索引。

## 4. 换形态的新成本（本轮未测，必须记账）

L1 的原话是"外部形式化 Agent **应优先快速回访原作者**"。
⇒ 全量臂的成本并没有消失，而是从"提交者写字"变成"**作者被打断的问答轮次**"。
这是另一种预算（同步阻塞、上下文切换），**比字节数更难估**，也最容易在评审时被漏掉。
待测指标建议：`每对象回访轮次`、`回访到答复的延迟`、`未完成确认的积压率`。
