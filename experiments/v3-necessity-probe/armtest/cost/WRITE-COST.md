# WRITE-COST · 创建一个 Assertion / 推理登记，三臂各要写多少（实测，非估算）

对象：**真实**那条判断 —— 「n2 自建工作点真束腰地板 939–970 nm ⇒ 290 nm 门不可达」及其推理。
三份文件都是**我真写了一遍**再称的：[A.md](A.md)（现状产物）· [Aplus.yaml](Aplus.yaml)（最小臂做满）· [B.yaml](B.yaml)（按 §3.3 / §5.1 字段逐一对应）。

| 方案 | 行 | 字节 | 汉字数 | 纯键结构字节 | 叶子字段 | **强制空填**（`[]`/`UNKNOWN`/`auto`） |
|---|--:|--:|--:|--:|--:|--:|

## 2. 三个读数（第三个最重要）

1. **实质语义内容只差约 2 倍**（汉字 84 → 126 → 176）。要写进系统的**新事实**并没有多到夸张。
2. **成本大头是序列化，不是思考**：B 有 **513 字节（27%）是纯键名/缩进**，且一个判断要拆成
   `AssertionRevision`(9 顶层字段 + `ResearchScope` 8 子项 + `TypedFormula`) **＋** `Argument`(13 字段) 两个对象。
   ⇒ **每对象 B ≈ A+ 的 5 倍写入量**。我先前在 ARM1 表里写的 `2.0 行/案` 是**新增事实的行数**，
   **不是对象写入量**——那是低报，已更正（见 §4）。
3. **B 的 5 处强制空填，恰恰就是它的价值所在**。`explicitCitations: []`（工作区内无基线）
   是 P6 能报警的原因；`obligationRefs: [OB-KS-密扫, OB-60k-复核, OB-Larmor-检查]` 是"未经进一步测试就宣布不可能"
   能被阻断的原因；`unknownConditions` 是 I4/I11 能被判的原因。
   **§3.3 的硬规矩「UNKNOWN 不能被空白/默认值伪装成已满足」才是全量臂真正的成本与真正的产品**——
   A+ 用一行「参照=无」也能表达同一件事，但它**不强制**：这一格空着没人报错。

## 3. 摊销与外推（外推部分标明是估算）

| 项 | 归属 | 成本 |
|---|---|---|
| `conceptRevisionRefs`（σ_r、真束腰、290 nm 门） | **跨案共享**，首案注册后复用 | 首案一次性；此后每条 1 行引用 |
| `evidenceRefs` 指向既有工件（json/log） | 工件已存在，只写 id | 1 行 |
| `inferenceSchemeRef`（局部最优→不可达） | 方案库，可注册复用 | 首案一次性 |
| Assertion 本体（含 scope 8 子项） | **每判断** | ≈24 行 |
| Argument（推理登记） | **每推理步骤** | ≈13 行 |

按已读片段计数（该报告 **7 处判断**：`:6,17,19,40,41,43,51`；**5 处推理**：fail-fast 证伪、地板分解 √(970²−236²)、
同号⇒C3≥0 的符号推演、−I 质量被否证、r_H 次要性）：
**每 run ≈ 7×24 + 5×13 ≈ 240 行**，而现状产物约 50 行 ⇒ **B 的实际写入量 ≈ 现状的 5 倍**（估算，按已读片段外推）。

## 4. 对 ARM1 的更正（不是补充，是改数）

`RESULT-ARM1.md` 与 **C-13** 的"写时代价 2.0 行/案"改为双列口径：

| | 新增事实 | **对象写入量** |
|---|--:|--:|
| A+ | ≈0–2 行/案 | **7 行/案**（6 个必填槽位） |
| B | 2.0 行/案 | **≈24–37 行/对象；≈240 行/run** |

**裁决是否翻转？不翻转，但代价侧的结论变硬**：
C-12 预注册指标是「最小臂能否支撑全部已运行谓词」——A+ 仍缺 2 个槽位，**"HSR 相对最小臂冗余"指控仍不成立**。
但成本比从"2 行 vs 0 行"变成 **"每对象 5×、每 run 5×"** ⇒ **"先把最小臂做满"从建议升级为明显占优**，
而 HSR 的投入必须**只**为那 2 类能力（测量级对象、跨面引用）+ **强制 UNKNOWN 显式化**这一条去买。

> 换一句可执行的话：**不要为"多写字"付钱，要为"不许把不知道写成看起来已满足"付钱。**
> A+ 缺的不是字段数，是**缺项即阻断**的权力；这一条其实可以在最小臂上先实现（把 6 个槽位做成必填 + 出口门）。
