## 3. 两处结论下调（不同意的部分，写明理由）

**(a) 「写时可拦 9/9 全『可』」——按原提问方式近乎同义反复，不能当证据。**
"如果当时把这条事实登记下来，能否避免该错误？"——**对任何因未登记而发生的错误，答案必然为"能"**，
这个提问**不可证伪**。有信息量的问法是：
① 写时该事实**是否已经存在**（可登记）；② 登记的**边际成本**是多少；③ 登记后**是否真有机验谓词**能消费它。
E5 的数据只支撑到"这三件在 9/9 上都成立"，**它支撑不了席位据此写的结论句**
"需要的是登记义务，**不是检索机制**"——那半句**被 E7 直接反驳**：
预算受限时**读到了记录仍被二手汇总否决**（P-A2），登记义务救不回来；
翻转结果的是**索引**。正确的合成见 §5。

**(b) 「FP(c)=0/83=0%」是人的判断，席位已自披露最严读法可把 (c) 推到 59.5%（66/111）。**
我按最严读法处理：**不得引用 0%**，只能引用"0%–59.5% 区间，取决于 (b)/(c) 边界"。

## 4. E5 真正值钱的那个数：**成本不对称**

```
111 次命中 / 4 个真实事件      ≈ 每抓 1 件要人工分诊 28 条
最严读法下 66/111 = 59.5% 可能是良性
写时代价：9 件事件 = 9 条声明（口径 / 前提+工件版本 / 终态）
```

**这才是支持"写时登记"的最强论据，而不是"写时能抓错"**：

> 把检查放在**读时**，成本是**每轮评审 ~111 条人工分诊**（其中一半以上可能是良性），
> 且对"包内无矛盾可配对"的类别**原理上抓不到**；
> 把检查放在**写时**，成本是**每条结论 1–3 行声明**，且**覆盖面是全类**。

**同一个机制（声明↔工件对账），换个位置放，性价比差两个数量级。**
这条比 E5 原本的结论句更弱也更稳：**它不主张写时能抓错，只主张写时更便宜且覆盖更全。**

## 5. E5 与 E7 的合成（两者不冲突，也不互相替代）

| | 读时通用对账（E5） | 写时登记义务（E4b′/E7-P-B） | 索引（E7-T-A/T-A2） |
|---|---|---|---|
| 真实材料命中率 | **4/9**（可测 4/6） | 不可测（同义反复风险） | 不可测 |
| 预算受限下的结论正确性 | — | **未改善**（P-B 0.38 错；P-A2 读到仍被否决） | **改善**（差 1/3 对 → 好 2/2 对） |
| 单件成本 | ~28 条人工分诊 | 1–3 行声明 | 每条记录 1 行主题 |
| 类别盲区 | 跨包前提更换、包内一致的口径换代 | 不能补"没读到" | 不能补"没写下来" |

→ **三者都要，但分工不同**：写时登记负责**便宜地覆盖面**，索引负责**在检索受限时把证据取回**，
读时对账负责**兜底抓自相矛盾**（并接受分诊成本）。
**当前 v3 设计的重心（对象类型 + 图 + 读时门禁）恰好把最贵的一格放得最重。**
