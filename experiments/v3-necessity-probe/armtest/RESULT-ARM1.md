# RESULT-ARM1 · 最小臂 vs 全量臂（案例 = REALTRACE-1 的 13 条真实条目）

**预注册**：判据写在跑之前 —— [CLAIMS.md](../CLAIMS.md) 的 **C-12** `design` 字段：
「可测化路径 = 最小臂 vs 全量臂跑同一批案例库，测**谓词可运行率 / 冲突阻断率 / 每案写行成本**」；
`metric` 字段给了裁决规则：「**最小臂能否支撑全部已声明谓词运行**（不能 → 过剩判断不成立；能且成本更低 → 部分过剩）」。
最小臂定义不作弊：逐字取 [VERDICT.md:284-289](../VERDICT.md#L284-L289)（索引 = 一行主题 + 量→定义出处 + 适用域；义务 = 口径 / 前提+工件版本 / 终态）。

## 1. 三臂

| 臂 | 记录形态 | 写时代价 |
|---|---|---|
| **A** | 真实 run 产物，**零改造**（`verification_report.md`、`full_record.txt`、`branch_selection.md`、json…原样） | 0 行 |
| **A+** | **最小臂按规约做满**（A + 一行主题 + 量→定义出处 + 适用域 + 结论侧 1–3 行声明） | ≈0–2 行 |
| **B** | 全量 HSR 记录面（对象身份、测量级对象、四本登记、类型化主张出口门、跨面引用） | 2.0 行/案（本表 26 行） |

谓词 7 个（P1 口径/优先级冲突、P2 比较端点设置指纹、P3 退化最优、P4 适用域与强度≤证据、P5 同点互斥值→禁止升级"已验证"、P6 不可达/跳过复核出口门、P7 跨 run 互斥裁决）。
**谓词只从 value 计算，不读任何"已捕获"标记。** 复跑：`node armtest/run.mjs`。

## 2. 结果

| 臂 | 谓词可运行 | 裁决正确 | 写时代价 |
|---|---|---|---|
| A 真实产物 | 11/13 | **9/13** | 0 |
| **A+ 最小臂做满** | — | **11/13** | ≈0–2 行/案 |
| B 全量记录面 | 13/13 | 13/13（**上限，见 §4**） | 2.0 行/案 |

**A+ 仍漏的恰好 2 条，且都在你要的那一列上**：

- **I4**（H2VN：同一 q\* 放大率 1.83/2.107/118.74 互斥，却写「**已验证**不可达」）→
  最小臂三条义务（口径/前提/终态）**没有测量级对象槽位**，装不下 `(观测点, 量, 值)` 三元组 ⇒ P5 不可运行。
- **I13**（H2VN 的不可达被 M3RD 用同种子解析落 M 残差 1e-11 证伪）→
  最小臂**无任何跨 run / 跨面引用槽位** ⇒ 别处已有反例，本工作区结构性看不见。
  且 B 臂也只是**标记**（HSR 自身 SD-20：跨面引用是断言不是可解析引用），仍需人裁。

**按 C-12 预注册规则裁决：最小臂**不能**支撑全部谓词 ⇒ "HSR 相对最小臂冗余"这一指控不成立（幅度词"显著"被自家门拦下，改用可核对形式）。**

## 3. 第二条独立证据：文本层谓词会误伤正面对照

首跑 A 臂把 **I10（L9T4）判成报警**——它是本轮唯一该放行的正面对照（发现矛盾、升级给人、**未**宣布目标不可达），
误报原因是否定盲区：正则命中了「未宣布目标**不可达**」里的"不可达"。
加否定守卫后放行；但这是**打补丁**，而 B 臂按**宣称类型**天然放行（`escalation` / `falsification-report` 不在受管 kind 内）。

> 这条正是你裁决的机验形态：**受管对象是"出口的判断"，不是"行动的选择"**。
> 类型化主张（B 臂）在这一点上不是冗余——文本层谓词做不到"拦下'不可能'而放行'我选 α≈1.32 / 我推翻自己的假设'"。
> 反向确认：I9（预写判别实验 + 诚实记录 fail-fast FAILED）两臂均放行，无误伤。

## 4. 三条必须挂在结论上的限定（否则这张表会被我滥用）

1. **B 臂 13/13 是"可表达性"上限，不是效度**：登记内容由我按规约**代填**（`items.json` 里 `intent:true`），
   等于自己出题自己答。它只证明"这些缺陷**能**被记录面表达并被谓词判对"，
   **完全不含"人/agent 会不会真填对"**——后者要另做写时实验。
2. **条目是我从单条轨迹挑的**（13 条，选择偏差未控），且真值部分来自 operator-only 报告；
   不能外推频率，不能当"HSR 降低失效率"的证据。
3. **谓词也是我写的**：偏袒方向未知；但 A/A+ 的漏检是**槽位缺失**（结构性、可核对），不是判断分歧。

## 5. 支持 / 不支持

- **支持**：C-12 方向获得第一条**非信念**证据（预注册判据、可复跑、A+ 有 2 条结构性无槽位）。
- **同时支持一条更难受的话**：**11/13 的保护价值来自最便宜的最小臂**，
  HSR 的**不可替代增量集中在 2/13**，但这 2 条恰好是"判断'不可能'对不对"所必需的两类能力
  （**测量自相矛盾检测** + **跨 run 反例可见性**）。
  → 预算顺序应是：**先把最小臂做满（几乎免费，拿下 11/13）**，再为那 2 条建测量级对象与跨面引用。
> 台账对应条目：**C-13**（JUDGED）。C-12 的问一按本表裁决，问二（形式化验证底座必要性）**尚未有任何数据**。

- **不支持**：拿本表主张"HSR 必要且充分"；也**不支持**反过来主张"HSR 无用"——A+ 是我理想化后的最小臂，真实里做不到做满。
- **下一步唯一有意义的实验**（本表证不了的那件事）：**写时双臂**——同一批案例让席位真写登记，
  测 A+ 的"做满"在实际写入时能否达成（若填不全，A+ 的 11/13 就是纸面数）。

## 6. 更正（2026-11-02，来自 WRITE-COST 实测）

本文件 §1/§2 的"写时代价"是**新增事实的行数**，不是**对象写入量**。真写一遍再称（`cost/WRITE-COST.md`）：

| | 新增事实 | 对象写入量 |
|---|--:|--:|
| A+ 最小臂做满 | ≈0–2 行/案 | **7 行/案**（6 必填槽位） |
| B 全量记录面 | 2.0 行/案 | **≈24–37 行/对象，≈240 行/run（≈现状 5×）** |

**裁决不翻转**（C-12 预注册指标问的是"最小臂能否支撑全部谓词"，A+ 仍缺 2 个槽位），
但**代价侧结论变硬**：先把最小臂做满从"建议"变成"明显占优"；HSR 的投入应只为
**测量级对象 + 跨面引用 + 强制 UNKNOWN 显式化** 这三样买。
B 的 5 处强制空填（`explicitCitations: []`、`obligationRefs` 三条、`unknownConditions`）
**既是它的成本也是它的产品**——A+ 能写"参照=无"，但**不强制**，空着没人报错。
